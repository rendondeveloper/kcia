# Governance Guardrail

The governance guardrail ensures traceability, ownership, and safe evolution of the control plane.

## Required Rules

- `kcia` is the organizational source of truth for the control plane
- guardrails, templates, and profiles must change through PRs
- `CODEOWNERS` is recommended for repositories that distribute the control plane
- sync behavior must use a pinned reference when a real distribution strategy exists
- milestones and decisions must record confirmed events only
